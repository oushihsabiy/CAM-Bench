### 1) `scripts/run_pipeline.sh`
作用：
- 统一入口脚本，内部会自动：
- 进入项目根目录
- 加载 `.env.local`（如果存在）
- 清理 `http_proxy/https_proxy` 等代理变量
- 调用 `python3 main.py <input_json> [额外参数]`
- 你在脚本后面追加的参数会原样透传给 `main.py`

启动方式：
```bash
bash scripts/run_pipeline.sh <input_json> [main.py 参数]
```

示例：
```bash
bash scripts/run_pipeline.sh data/Numerical_Optimization_Chp2.json --resume-from 20 --no-preprocess
```

启用 `codex_cli` 的示例：

```bash
bash scripts/run_pipeline.sh data/Numerical_Optimization_Chp2.json --config config.codex.json
```

```bash
bash scripts/run_pipeline.sh preprocessed_data/convex_optimization_Chp2.json --no-preprocess --resume-from 2 --resume-translate
```

### 1.1) `scripts/run_preprocess.py`（仅预处理）
作用：
- 只跑预处理，不进入翻译/编译阶段。
- 默认（不加参数）自动遍历 `data/*.json`，逐个预处理到 `preprocessed_data/<stem>.json`。
- 已有产物会自动跳过（可用 `--force` 强制重跑）。
- 也支持指定单文件预处理。
- 支持 `--show-config` 显示当前生效配置（`config.json` + `settings.json`叠加）并退出。
- 支持指定使用哪个配置文件（例如 `--config config5.json`，或简写 `--config5.json`）。
- 预处理失败会实时写入 `logs/failure_reports/realtime_failures.jsonl`，并将对应题号的预处理块（若无则回退为同结构兜底块）追加到 `error_problem/errors.json`。

启动方式：
```bash
/root/workspace/benchmark/.venv/bin/python scripts/run_preprocess.py [input_json] [--force]
```

示例：
```bash
# 1) 不加参数：批量处理 data/*.json，已有产物自动跳过
/root/workspace/benchmark/.venv/bin/python scripts/run_preprocess.py

# 2) 指定单文件（相对路径）
/root/workspace/benchmark/.venv/bin/python scripts/run_preprocess.py data/convex_optimization_Chp4-2.json

# 3) 指定单文件（绝对路径）
/root/workspace/benchmark/.venv/bin/python scripts/run_preprocess.py /root/workspace/benchmark/JSON2LEAN/data/convex_optimization_Chp4-2.json

# 4) 单文件强制重跑（即使 preprocessed_data 已有产物）
/root/workspace/benchmark/.venv/bin/python scripts/run_preprocess.py data/convex_optimization_Chp4-2.json --force

# 5) 仅显示当前生效配置并退出（不执行预处理）
/root/workspace/benchmark/.venv/bin/python scripts/run_preprocess.py --show-config

# 6) 指定使用 config5.json（标准写法）
/root/workspace/benchmark/.venv/bin/python scripts/run_preprocess.py data/convex_optimization_Chp4-2.json --config config5.json

# 7) 指定使用 config5.json（简写，与你说的形式一致）
/root/workspace/benchmark/.venv/bin/python scripts/run_preprocess.py data/convex_optimization_Chp4-2.json --config5.json
```

### 2) `scripts/run_with_autoscan.sh`
作用：
- 包装执行“原始命令”后，自动触发 `ensure_all_outputs.sh`
- 适合一键“先跑主任务，再自动补齐缺失输出”
- 返回码规则：
- 默认：原始命令失败则直接退出，不继续 autoscan
- 若设置 `AUTOSCAN_AFTER_FAIL=1`，即使原始命令失败也继续跑 autoscan
- autoscan 失败时，脚本返回 autoscan 的错误码

启动方式：
```bash
bash scripts/run_with_autoscan.sh '<原始命令>'
```

示例：
```bash
bash scripts/run_with_autoscan.sh 'bash scripts/run_pipeline.sh data/convex_optimization_Chp2.json --resume'
```

强制“主命令失败后也继续 autoscan”：
```bash
AUTOSCAN_AFTER_FAIL=1 bash scripts/run_with_autoscan.sh 'bash scripts/run_pipeline.sh data/convex_optimization_Chp2.json --resume'
```

### 3) `scripts/ensure_all_outputs.sh`
作用：
- 扫描 `data/*.json`，检查每个 stem 是否同时具备：
- `preprocessed_data/<stem>.json`（且为非空、可解析 JSON list）
- `lean/LeanProject/<stem>.lean`
- 若缺失会自动重试调用 `run_pipeline.sh` 补齐
- 默认重试上限 `MAX_RETRIES=3`，单次命令超时 `CMD_TIMEOUT_SEC=1800`

启动方式：
```bash
bash scripts/ensure_all_outputs.sh
```

可选环境变量：
```bash
MAX_RETRIES=5 CMD_TIMEOUT_SEC=2400 bash scripts/ensure_all_outputs.sh
```

### 4) `scripts/postprocess_lean.py`
作用：
- 对单个 Lean 文件执行后处理（调用 `json2lean.postprocess_lean.postprocess_lean_file`）
- 常用于你手工改动或单文件生成后，统一规范注释和结构细节

启动方式：
```bash
python3 scripts/postprocess_lean.py <lean_file>
```

示例：
```bash
python3 scripts/postprocess_lean.py lean/LeanProject/convex_optimization_Chp2.lean
```

---

### 4.1) `scripts/split_single_lean.py`（只拆分一个 Lean 文件）
作用：
- 只处理你明确指定的一个 `.lean` 文件，不会扫描整个目录
- 输出到你指定的目录，并在运行时打印完整命令、输入路径、输出路径

启动方式：
```bash
python3 scripts/split_single_lean.py --input-lean <input_lean_file> --output-dir <output_dir>
```

示例：
```bash
python3 scripts/split_single_lean.py \
  --input-lean /home/a776/workdocuments/JSON2LEAN/lean/LeanProject/convex_optimization_Chp2.lean \
  --output-dir /home/a776/workdocuments/JSON2LEAN/lean/split_out
```

#### 16.2 不预处理，只翻译（从指定序号开始）
说明：必须带 `--resume-translate`，否则会进入“仅编译续跑”模式而不是翻译。

```bash
env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY -u all_proxy -u ALL_PROXY \
bash scripts/run_pipeline.sh \
preprocessed_data/convex_optimization_Chp5.json \
--no-preprocess \
--resume-from 20 \
--resume-translate
```

#### 16.3 只运行语义检查（从指定序号开始）
说明：需要先有对应的 `lean/LeanProject/<stem>.lean`（可先跑一次翻译）。

```bash
env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY -u all_proxy -u ALL_PROXY \
python3 main.py \
data/convex_optimization_Chp5.json \
--semantic-only \
--resume-from 20
```
