# 推荐统计标准：8 小时、原题、无伪证明、去跨题 import

生成日期：2026-05-05

## 结论

我建议把主统计标准改成：

> **Strict-Isolated-8h**：8 小时以内完成；最终 Lean 文件可验；不计 `exact?`、`sorry`、`sorryAx`、`admit` 伪证明；不计修题成功；m2f 不允许跨题 import。`history_log_sum` 只表示日志/时间来源，不等同于引用其他题，因此主正确率里不扣。

这个标准下：

| agent | 成功题数 | 成功率 |
|---|---:|---:|
| m2f | 143 / 200 | 71.5% |
| aristotle | 125 / 200 | 62.5% |

这个口径比之前的 `Strict-Direct-8h` 更合理：`history_log_sum` 是历史日志累计出来的时间/token 字段，不是证明依赖。只要最终 Lean 文件本身没有伪证明、没有跨题 import，应该算作解出。相反，跨题 import 是真实证明依赖，会破坏“单题隔离”设定，所以应从主榜去掉。

同时保留一个敏感性口径：

| 口径 | m2f | aristotle | 用途 |
|---|---:|---:|---|
| 8h + 无伪证明 + 去修题，m2f 允许 import | 147 | 125 | 展示 m2f 原始 8h 结果。 |
| **Strict-Isolated-8h，允许 history，去跨题 import** | **143** | **125** | 推荐主结果。 |
| Strict-Direct-Isolated-8h，再排除 `history_log_sum` | 121 | 125 | 只作 direct-run 敏感性分析，不建议做主榜。 |

## 为什么这样定义

### `history_log_sum` 应该算正确

m2f 的 `history_log_sum` 表示 `per_problem_summary.csv` 里的时间/token 不是单个 reported run 给出的，而是从历史日志累计得到。它影响的是运行成本统计的可比性，但不说明证明引用了别的题。

因此：

- 对“最终是否解出原题”：应该计入。
- 对“单次 direct run 成本”：可以单独做敏感性分析。
- 不应该把 `history_log_sum` 当成伪证明或跨题引用。

### 跨题 import 应该从主榜去掉

Aristotle 是一题一题独立做，不会看到或引用其他题。m2f 的部分文件会 import 其他 problem 文件，这会让该题证明依赖其他题的定义、引理甚至未完成证明。

因此主榜为了强调 benchmark 的单题隔离价值，应去掉 m2f 的跨题 import 成功题。

## 对论文/报告的建议表述

建议主文使用：

> We report a strict isolated 8-hour score. A problem is counted as solved only if the original theorem is proved without pseudo-proofs or statement repair. For m2f, we additionally exclude cross-problem imports to match the single-problem setting used by Aristotle. Historical log aggregation is not treated as a proof dependency and is reported separately as a cost-accounting sensitivity. Under this protocol, m2f solves 143/200 problems and Aristotle solves 125/200, while 34 problems remain unsolved by both systems.

中文可以写：

> 在 8 小时、原题、无伪证明、去跨题 import 的严格单题隔离口径下，m2f 解出 143/200，Aristotle 解出 125/200。`history_log_sum` 不作为扣分项，因为它是日志成本来源，不是证明依赖；但 direct-run-only 结果作为敏感性分析单独报告。该结果显示 benchmark 既有相当数量的可解题，又保留 34 道两系统都未解决的 hard cases，因此处于未饱和且有区分度的难度区间。

## 一句话结论

最合理的主标准是：

> **8 小时内，原题证明，无 `exact?/sorry/sorryAx/admit`，Aristotle 去 `yes -xiu`，m2f 去跨题 import，但不因为 `history_log_sum` 扣正确性。**

主结果：m2f **143/200 = 71.5%**，Aristotle **125/200 = 62.5%**。
