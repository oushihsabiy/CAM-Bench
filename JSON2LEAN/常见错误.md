# JSON2LEAN Compilation Error Reference

This document is a quick-reference guide for fixing common Lean 4 compilation errors produced during JSON-to-Lean translation. Each entry lists the error message pattern, root cause, and the fix to apply.

---

## 1. `λ` Used as an Identifier → `unexpected token`

**Error:** `unexpected token 'λ'; expected '_' or identifier`

**Cause:** In Lean 4, `λ` is a reserved keyword (equivalent to `fun`) and cannot be used as a variable name. LLMs frequently use λ (Lagrange multiplier, eigenvalue, etc.) directly as an identifier.

**Fix:** Replace every variable-name `λ` with `lam` or another non-reserved name.

```lean
-- ✗ Wrong
∀ λ : ℝ, ...
∃ λ : Fin k → ℝ, ...

-- ✓ Correct
∀ lam : ℝ, ...
∃ lam : Fin k → ℝ, ...
```

---

## 2. Matrix Multiplication Symbol `⬝` → `expected token`

**Error:** `expected token` near `A ⬝ B` or `Qᵀ`

**Cause:** Lean 4 / Mathlib no longer supports the `⬝` notation for matrix multiplication, and the superscript `ᵀ` for transpose may not be in scope.

**Fix:** Use `*` for matrix multiplication and `.transpose` for the transpose operation.

```lean
-- ✗ Wrong
V.transpose ⬝ V = 1
Q ⬝ Matrix.diagonal lam ⬝ Qᵀ

-- ✓ Correct
V.transpose * V = 1
Q * Matrix.diagonal lam * Q.transpose
```

---

## 3. `Fin n → ℝ` vs `EuclideanSpace ℝ (Fin n)` Type Mismatch

**Error:** `type mismatch` / `application type mismatch` — argument has type `Fin n → ℝ` but expected `EuclideanSpace ℝ (Fin n)`, or vice versa.

**Cause:** `EuclideanSpace ℝ (Fin n)` is an alias for `PiLp 2 (fun _ : Fin n => ℝ)` and is not directly compatible with the bare function type `Fin n → ℝ`.

**Fix:**
- Use `EuclideanSpace.equiv` or `.ofLp` / `.toLp` to convert between the two.
- If a function signature uses `EuclideanSpace`, pass arguments of that same type.
- Prefer `!₂[...]` for vector construction; avoid unsafe coercions like `((fun _ => ...) : EuclideanSpace ...)`.

---

## 4. `has already been declared`

**Error:** `` `dualCone` has already been declared ``

**Common repeated names:** `dualCone`, `QuasiconvexOn`, `SemidefiniteProgram` family.

**Cause:** The same name was defined multiple times across problems, or it conflicts with an existing Mathlib definition.

**Fix:**
- Prefix every custom definition with the problem number, e.g. `dualCone_ex2_31`.
- Before defining a name, check whether Mathlib already has it: `#check dualCone`.

---

## 5. `failed to synthesize` — Missing Type Class Instance

**Error:** `failed to synthesize instance of type class`

**Common missing instances:**
| Missing instance | Cause | Fix |
|---|---|---|
| `Inner ℝ (n → ℝ)` | Bare function type has no inner product instance | Use `EuclideanSpace ℝ (Fin n)` |
| `AddCommMonoid E` / `HSMul ℝ E` | Generic variable `E` missing constraints | Add `[AddCommMonoid E] [Module ℝ E]` etc. |
| `SMul ℝ EReal` | `ℝ` cannot directly smul `EReal` | Avoid mixing `ℝ` scalars with `EReal` |
| `Membership (Fin p → ℝ) (Set (Fin m → ℝ))` | Dimension mismatch `p ≠ m` | Keep dimension variables consistent |

**Fix:**
- For bare `n → ℝ` when an inner product is needed, switch to `EuclideanSpace ℝ (Fin n)` or add `open scoped RealInnerProductSpace`.
- Add the full set of required constraints to generic type variables.
- Do not mix different dimension parameters in the same statement.

---

## 6. `Unknown constant` — Nonexistent API

**Error:** `` Unknown constant `Matrix.dotProduct` `` etc.

**Common hallucinated APIs and their correct replacements:**
| Hallucinated | Correct |
|---|---|
| `Matrix.dotProduct` | `dotProduct` (no `Matrix.` prefix) |
| `Matrix.blockMatrix` | `Matrix.fromBlocks` |
| `Matrix.singularValues` | Not in Mathlib — define manually or reformulate |
| `Matrix.perm` | `Matrix.submatrix` or `Matrix.reindex` |

**Fix:** Verify every API name against Mathlib documentation before use. Do not guess namespace prefixes from memory.

---

## 7. Inner Product Notation and Scope

**Error:** Parse errors or scope issues around `⟪x, y⟫`.

**Fix:**
- Preferred: use the explicit form `inner ℝ x y`.
- If bracket notation is required, add `open scoped RealInnerProductSpace` at the top of the file.
- **Never** use `⟪x, y⟫_ℝ` — this syntax does not exist.

---

## 8. Miscellaneous Syntax Errors

| Error message | Likely cause | Fix |
|---|---|---|
| `unexpected token ','; expected command` | Trailing comma in a tuple or structure | Remove the extra comma |
| `unexpected token ':'; expected '[', '{', '\|', '⦃' or term` | Type annotation in wrong position, often from `λ` as variable (see §1) | Fix the identifier name first |
| `unexpected token 'in'; expected ','` | `∑ i in s` syntax | Check the correct `Finset.sum` spelling: `∑ i ∈ s, ...` |
